# Деплой на Netlify — пошагово

## Структура файлов

```
yt-downloader/
├── index.html                        ← фронтенд (сайт)
├── netlify.toml                      ← конфиг Netlify
└── netlify/
    └── functions/
        ├── get_url.py                ← Python-функция (бэкенд)
        └── requirements.txt          ← зависимости Python
```

---

## Способ 1: через GitHub (рекомендуется)

1. Создай репозиторий на https://github.com/new
2. Загрузи все файлы (сохранив структуру папок)
3. Зайди на https://app.netlify.com → **Add new site → Import an existing project**
4. Выбери GitHub, найди свой репозиторий
5. Настройки сборки оставь по умолчанию (Netlify сам считает netlify.toml)
6. Нажми **Deploy site**

Через ~2 минуты сайт будет доступен на `https://твоё-имя.netlify.app`

---

## Способ 2: через Netlify CLI (drag & drop папки)

1. Зайди на https://app.netlify.com
2. На главной странице перетащи папку `yt-downloader/` в область **"Drag and drop your site output folder here"**
3. Готово! Но этот способ не поддерживает Functions — **используй Способ 1**

---

## Важные ограничения бесплатного плана Netlify

| Параметр | Лимит |
|----------|-------|
| Таймаут функции | **10 секунд** |
| Запросов в месяц | 125,000 |
| Пропускная способность | 100 GB |

> ⚠️ **10 секунд может не хватить** для некоторых видео.
> Если будешь видеть ошибки таймаута — рассмотри Способ 3.

---

## Способ 3: Railway / Render (если нужен полноценный Python-сервер)

Если таймаут Netlify мешает, можно развернуть Flask-сервер на:
- **Railway** (https://railway.app) — бесплатно $5/мес кредитов
- **Render** (https://render.com) — бесплатный tier

Для этого скажи, и сделаю отдельную версию с Flask.

## Как работает сайт

1. Пользователь вставляет ссылку на YouTube
2. Браузер отправляет POST-запрос на `/.netlify/functions/get_url`
3. Python-функция использует `yt-dlp` чтобы извлечь прямую ссылку на файл
4. Браузер показывает кнопку скачивания с прямой ссылкой
5. Пользователь скачивает файл напрямую с серверов YouTube

> Файлы НЕ хранятся на сервере — yt-dlp только получает ссылку.
